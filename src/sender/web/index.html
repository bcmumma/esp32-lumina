Status light

The RGB light on the Lumina S3 board: off keeps it dark at all times. On, it shows green when connected and blinks blue or red otherwise.

On this board the RGB light shares GPIO48 with the PCM1808's audio data, so Lumina can't switch it: it shows whatever the audio line sends it. To free it, move the PCM1808 OUT wire to another pin (see docs/HARDWARE.md), cover the light, or open the board's RGB jumper.

Kick looks

Strands

Room 1's receiver drives strands 1–2; room 2's receiver (the receiver_room2 build) drives strands 3–4 on its own first two outputs, so set strands 3–4 to the pins wired in room 2 (e.g. 33 and 25). Set Active strands to 3 or 4 to light room 2.

Pin, count, and type changes make the receiver reconfigure. Proven pins: 33, 25, 26, 27. A strand switched off here stays off when you pick a look.

Colour calibration

Tests put every active strand on a solid colour. Pick a look again afterwards.

Audio input

Receiver updates

Puts a room receiver on the home Wi-Fi for 10 minutes so the PC can send it new firmware (Claude runs tools/ota_update.py). The lights keep running meanwhile.
